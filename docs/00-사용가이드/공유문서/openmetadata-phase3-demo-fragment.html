3차 시연문서 초안

코드 변경부터 검사 결과와 배포 판단까지

실제 제품 소스와 로컬 검사 결과를 연결해 보여줍니다. 다음 공식 버전과 행내 실행 환경이 필요한 항목은 완료된 결과로 표시하지 않습니다.

현재 최종 판단 BLOCK · 운영 배포 진행 불가

소스 변경 검사는 통과했지만 실제 공식 업그레이드, 행내 API·화면·DB 테스트와 배포본 일치 검사가 남아 있습니다.

03

실제 코드가 어떻게 달라졌나

BANK-OM-001의 InstanceCode를 대표 사례로 사용합니다. 전체 11개 커스터마이징 중 한 사례입니다.

공식 공용 코드Entity.java

OpenMetadata가 인식할 엔티티 이름에 instanceCode를 연결합니다.

→
행내 추가 API 코드InstanceCodeResource.java

/v1/instanceCodes API와 조회·등록·변경 동작을 제공합니다.

→
행내 추가 스키마instanceCode.json

InstanceCode 데이터의 필드와 형식을 정의합니다.

Entity.java · 공식 공용 파일의 실제 변경
공식 원본 · afcb2d2… 
public static final String FILE = "file";
public static final String SPREADSHEET = "spreadsheet";
public static final String WORKSHEET = "worksheet";

public static final String GLOSSARY = "glossary";
행내 코드 · a2566fac…에서 추가 
public static final String FILE = "file";
public static final String SPREADSHEET = "spreadsheet";
public static final String WORKSHEET = "worksheet";
public static final String INSTANCE_CODE = "instanceCode";

public static final String GLOSSARY = "glossary";

이 변경으로 새 API 코드가 Entity.INSTANCE_CODE를 사용해 OpenMetadata의 공통 엔티티 처리 구조에 연결됩니다.

InstanceCodeResource.java · 커스터마이징으로 추가된 실제 파일
공식 원본 
파일 없음

공식 1.13.1에는
InstanceCode 전용 API 파일이 없습니다.
행내 코드 · 새 파일 527줄 
@Path("/v1/instanceCodes")
@Collection(name = "instanceCodes")
public class InstanceCodeResource
    extends EntityResource<InstanceCode,
      InstanceCodeRepository> {

  public InstanceCodeResource(

Entity.java의 공통 등록값과 새 API 파일은 서로 독립된 변경이 아니라 함께 동작하는 코드입니다.

04

변경관리표와 Git 기록이 어떻게 연결되나

BANK-OM ID는 업무 기능 번호이고, Git commit SHA는 해당 코드 상태를 식별하는 값입니다.

1. BANK-OM-001 Manifest 
customization_id: BANK-OM-001
status: active
kind: core-patch
title: InstanceCode

implementation:
  allowed_changed_paths:
    - .../Entity.java
    - .../InstanceCodeResource.java
    - .../instanceCode.json
  required_changed_paths:
    - .../InstanceCodeResource.java
    - .../instanceCode.json

assurance:
  contracts:
    - CONTRACT-INSTANCE-CODE

실제 Manifest에는 전체 변경 파일 48개가 개별 경로로 등록돼 있으며, 화면에는 관계 설명에 필요한 대표 파일만 줄여 표시했습니다.

2. 개발자가 작성하는 커밋 메시지 
git commit \
  -m "add InstanceCode customization" \
  -m "Customization-ID: BANK-OM-001"
3. 실제 Git 기록 
a2566fac32 add InstanceCode customization
Customization-ID: BANK-OM-001

BANK-OM-001은 사람이 발급한 기능 ID이고, a2566fac…은 Git이 생성한 해당 커밋의 SHA입니다.
