3. 단계별 명령

3-1. Git 설치 확인

수행 내용 — 이 컴퓨터에서 Git을 사용할 수 있는지 확인합니다.

git --version

예상 결과 — git version 2.x.x. command not found이면 Git 설치 전까지 중단합니다.

3-2. OM_TEMP 읽기 권한 확인

수행 내용 — 인터넷 연결과 코드 저장소 읽기 권한을 확인합니다. 파일은 수정하지 않습니다.

git ls-remote --heads https://github.com/easyseop/OM_TEMP.git

예상 결과 — SHA와 branch 이름이 여러 줄 출력됩니다.

3-3. 실제 커스터마이징 원본 확인

수행 내용 — custom branch 복원에 사용할 실제 원본 commit을 확인합니다.

git -C /Users/seop/Documents/Codex/2026-07-24/sites-plugin-sites-openai-bundled/work/review-kb-openmetadata rev-parse refs/remotes/origin/main

예상 결과 — 2c2347043235aa2a4ecba4729774c770fcee5d67

3-4. 공식 1.13.1 기준 확인

수행 내용 — official branch에 기록할 공식 릴리스 commit을 확인합니다.

git -C /Users/seop/Documents/Codex/2026-07-24/sites-plugin-sites-openai-bundled/work/review-kb-openmetadata rev-parse refs/tags/1.13.1-release

예상 결과 — afcb2d2cd7e7c28f1d0ce60538c60a96f4eb9dc9

3-5. 작업 폴더로 이동

수행 내용 — 반복 작업에 사용하는 ~/om-work로 이동합니다. ~는 현재 사용자의 홈 폴더인 /Users/seop을 뜻합니다.

cd ~/om-work
3-6. OM_TEMP를 별도 폴더에 clone

수행 내용 — 기존 작업과 분리된 om-temp-real-1.13.1 폴더를 만듭니다.

git clone --filter=blob:none --no-checkout https://github.com/easyseop/OM_TEMP.git om-temp-real-1.13.1

--filter=blob:none은 필요한 파일만 나중에 받고, --no-checkout은 아직 코드 파일을 펼치지 않는 옵션입니다. 결과는 ~/om-work/om-temp-real-1.13.1에 생성되며 기존 ~/om-work/OM_TEMP는 수정되지 않습니다. 같은 폴더가 이미 있으면 재실행하지 않습니다.

3-7. 실제 원본 폴더 연결

수행 내용 — 실제 원본을 kb-source라는 이름으로 조회할 수 있게 연결합니다. 원본 파일은 수정하지 않습니다.

git -C ~/om-work/om-temp-real-1.13.1 remote add kb-source /Users/seop/Documents/Codex/2026-07-24/sites-plugin-sites-openai-bundled/work/review-kb-openmetadata

필요성 — 새로 clone한 폴더는 GitHub의 easyseop/OM_TEMP만 알고 있습니다. 실제 커스터마이징 코드는 별도 로컬 폴더에 있으므로 새 작업 폴더에 그 위치를 먼저 알려줘야 합니다.

이 명령은 코드를 복사하지 않습니다. kb-source라는 이름과 실제 원본 폴더의 경로만 Git 설정에 기록합니다.

remote kb-source already exists이면 아래 명령으로 기존 주소를 확인합니다.

git -C ~/om-work/om-temp-real-1.13.1 remote -v

적용 조건 — 실제 원본에서 custom/om-1.13.1을 처음 복원하는 과정을 재현할 때 실행합니다. 이미 만들어진 원격 branch를 내려받기만 할 때는 실행하지 않습니다.

3-8. 필요한 기준 가져오기

수행 내용 — 실제 원본 commit과 공식 1.13.1 tag를 새 작업 폴더로 가져옵니다. branch는 아직 만들지 않습니다.

git -C ~/om-work/om-temp-real-1.13.1 fetch kb-source refs/remotes/origin/main:refs/remotes/kb-source/main refs/tags/1.13.1-release:refs/tags/1.13.1-release

필요성 — 3-7은 원본 위치만 등록합니다. 3-8의 fetch가 실제 Git 이력을 읽어 와야 원본과 원격 custom branch의 동일성을 확인할 수 있습니다.

  • 실제 커스터마이징 commit → custom/om-1.13.1 생성에 사용
  • 공식 1.13.1-release tag → official/om-1.13.1 생성에 사용

예상 결과 — kb-source/main과 1.13.1-release가 추가됐다는 메시지가 표시됩니다.

중단 조건 — couldn't find remote ref 또는 not a git repository가 나오면 branch를 만들지 말고 3-3·3-4의 원본 경로와 기준값을 다시 확인합니다.

기존 원격 branch 활용 시 — 현재 easyseop/OM_TEMP 원격에는 official/om-1.13.1과 custom/om-1.13.1이 이미 있습니다. 최초 복원을 재현하지 않는다면 3-7·3-8 대신 git fetch origin으로 두 원격 branch를 받습니다.
3-9. Git 작성자 확인

수행 내용 — 향후 승인된 코드 변경 commit에 기록될 이름과 이메일을 확인합니다.

git -C ~/om-work/om-temp-real-1.13.1 config user.name
git -C ~/om-work/om-temp-real-1.13.1 config user.email

빈 출력이면 아래 방법으로 본인 정보를 등록합니다. 다른 사람의 정보를 임의로 사용하지 않습니다.

작성자 정보 미설정 시 조치 — 다음 설정은 ~/om-work/om-temp-real-1.13.1에만 적용되며 다른 Git 저장소는 바뀌지 않습니다.

첫 번째 명령의 JISEOP LEE를 commit에 표시할 본인 이름으로 확인하거나 바꾼 뒤 실행합니다.

git -C ~/om-work/om-temp-real-1.13.1 config --local user.name "JISEOP LEE"

두 번째 명령의 YOUR_GITHUB_EMAIL을 본인 GitHub 계정의 이메일 또는 GitHub에서 제공한 비공개 이메일 주소로 바꾼 뒤 실행합니다. YOUR_GITHUB_EMAIL 문구를 그대로 등록하면 안 됩니다.

git -C ~/om-work/om-temp-real-1.13.1 config --local user.email "YOUR_GITHUB_EMAIL"

이 정보는 향후 이 작업 폴더에서 만드는 Git commit의 작성자로 기록됩니다. GitHub 로그인이나 push 권한을 설정하는 명령은 아닙니다.

등록 결과 확인 — 등록 후 다음 두 명령을 각각 실행합니다.

git -C ~/om-work/om-temp-real-1.13.1 config --local --get user.name
git -C ~/om-work/om-temp-real-1.13.1 config --local --get user.email

예상 결과 — 첫 번째 결과에 본인 이름, 두 번째 결과에 본인 이메일이 표시됩니다.

중단 조건 — 여전히 빈 출력이거나 다른 사람의 정보가 나오면 commit을 만들지 않습니다.

3-10. 현재 상태 확인

수행 내용 — 새 작업 폴더가 준비됐는지 확인합니다.

git -C ~/om-work/om-temp-real-1.13.1 status --short

예상 결과 — 현재 기준에서는 D가 13,853줄 표시됩니다. 이는 --no-checkout으로 전체 파일을 아직 펼치지 않아 나타나는 상태이며, 사용자가 파일을 삭제한 결과가 아닙니다. 일반 git add나 git commit으로 이 목록을 반영하지 않습니다.

4. 사전 준비 완료 기준

  • Git 버전이 정상 출력됩니다.
  • OM_TEMP branch 목록을 읽을 수 있습니다.
  • 실제 원본 commit이 2c234704…입니다.
  • 공식 1.13.1 commit이 afcb2d2…입니다.
  • ~/om-work/om-temp-real-1.13.1 작업 폴더가 있습니다.
  • 기존 ~/om-work/OM_TEMP의 branch와 파일은 변경되지 않았습니다.
  • kb-source가 실제 원본 폴더를 가리킵니다.
  • Git 작성자 이름과 이메일이 비어 있지 않습니다.
중단 조건 — 하나라도 맞지 않으면 branch 연결 단계로 이동하지 않습니다.
