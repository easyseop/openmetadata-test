| 용어 `소유정보` | 수정 | 화면에서는 `경로–BANK-OM 연결표`로 설명하고 실제 파일명은 유지 |
| 현재 기능과 제안 기능 분리 | 분리 | 추가 개발 항목을 별도 설계 제안 문서로 이동 |

## 검증 결과

- 문서 생성기: Python 렌더러 2개와 Node.js 위키 생성기 실행 완료
- 문법 검사: Python·JavaScript 문법 검사 통과
- 자동화 회귀 검사: 등록 준비와 업그레이드 실행 관련 test 25개 통과
- 문장 검토표: 총 1,097건(유지 645, 수정 365, 삭제 4, 추가 83) 생성
- 브라우저 확인: 메뉴 57개 표시, 가로 넘침 없음, 콘솔 오류·경고 없음
- 핵심 흐름 대조: T42 실행 시점, `plan → 담당자 승인 → apply`, T90의 실제 12단계 ID,
  Manifest 경로 자동 제안 조건이 위키와 요약 가이드에서 동일하게 표시됨
