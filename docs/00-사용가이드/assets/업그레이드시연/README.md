## 담지 않은 것

준비 단계 화면(clone, 의존성 설치, 브랜치 확인) 세 장과 등록표 원문 한 장은
받았지만 넣지 않았습니다. 앞의 셋은 로그로 충분하고, 등록표는 원문이 화면에
그대로 쏟아져 읽히지 않습니다. 등록표의 요점인 "손댄 파일 전부"와 "없어지면
안 되는 파일"의 대비는 발표 자료 안에 표로 설명해 두었습니다.
